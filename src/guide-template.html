课堂使用说明

把纸上的题，变成可以观察的空间。

  1. 从目录选择题组和小问。新小问自动准备关键状态，当前答案先隐藏。
  2. 在原题图与三维图之间对照；点击“展开下一步解析”逐步讲解。磁感线、受力和合力可独立开关。
  3. 先选“观察部位”，再按需要开启右手或左手。手势按钮互不强制接力；点击下一步手势，查看各指对应关系。
  4. “放大局部”便于看掌心和手指；“题图视角”返回全景。平面、俯视、从左看对应不同观察方向，正交适合几何判断。
  5. 进入自由探究后调整各题参数。返回题设会恢复原题条件，重新隐藏答案。方向题只显示趋势，不把示意流速当作真实运动速度。
  6. 点击保存备课，下载状态文件；在教室打开本HTML，再载入状态。题号、视角及探究参数会恢复，答案与手模型先隐藏。

电源始终使用一长一短平行线；电流、磁场和力分别使用有向流线、细场线和实心箭头。数学公式与字体已内嵌，断网首次打开也可使用。

空格播放／暂停变化，R 还原本问；在输入框和对话框内不触发快捷键。支持 WebGL 2 的 Edge / Chrome 可直接打开。

模型与来源

原题、原图来自本地导学案。计算题采用题给近似值，探究模式按实际角度计算。磁体场与缺少数值的题景标为示意，不从题图像素推测真实场强；非匀强场用局部电流元判断受力。
