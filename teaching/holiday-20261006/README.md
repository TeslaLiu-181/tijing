## 模型与解析边界

- 未给定数值的题目使用明确标注的演示赋值，题设关系以连续定义保存。
- 回旋加速器分别提供有限狭缝中的实际原生运动与理想最大轨道。有限狭缝首次出边的动能不能冒充题设中以轨道半径 R 定义的理想最大动能。
- 结合碰撞分别播放碰撞前与碰撞后的原生运动，用动量守恒衔接初态，没有宣称原生引擎增加了碰撞检测。
- 作业5第11题采用原题 m、q、E、B。抛物线边界以18段多边形表示，各发射点是精确结点；规定的水平发射轨迹始终处于真实场域和该多边形内，所以本组受场过程相同。这种构造不适用于任意新方向的越界问题。
- 原解析校勘写在对应题目中：作业3第7题按实际选项应为 B；作业5第11题第二次过 y 轴的位置应为 (0, −10 m)。条形磁场题的电性以原图转向判定，正方形题另说明相切的边界约定。
- 作业2第10题最后一行“AC”应为 C。作业6第10题最低点的磁力向下，甲轨道压力为 `3mg + qB√(2gR)`，原答案 B 不变。
- 作业4第7题和作业6第3题的终端速度是渐近极限，场景不会伪造有限时刻精确达到。作业6第12题将摩擦耗散与电势能增加分开显示。
- 静止题给出真实平衡量；弹簧、电荷分离、电磁铁等题中没有给出的形变幅度或微观弛豫时间只作明确标注的趋势示意。带电球摆采用球面约束 RK4 求解，核对长度、机械能与绕磁场轴的正则角动量。粗糙面和接触换向采用解析速度关系；组合轨道在事件点衔接，核对做功与动能。
- 三角形线圈的转动中间过程以圆柱场域作为演示延拓，用投影重叠面积计算通量，不把有界场误当成整面匀强磁场。初末通量采用题设的精确关系。
