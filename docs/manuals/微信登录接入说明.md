# 微信登录接入说明

> 本文为保留的功能说明，已清理原部署标识。当前版本、安装步骤和导出差异以根目录 README、PROVENANCE.json 及公开部署指南为准；历史验收记录不是本次交付重新执行的结果。

当前约定：先交付账号与个性化系统，微信官方网站应用和回调域名尚未具备，因此功能保持关闭。已有接入代码与合成协议测试不代表真实微信登录已完成联调。

## 官方前提

2026-10-09 已读取 [微信官方的网站应用登录文档](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)。网站登录使用 OAuth 授权码流程，需有审核通过的网站应用和微信登录能力。微信开放平台中配置的授权回调域须与实际请求的回调域匹配。

官方页面可能提供二维码登录或已登录微信客户端的快速确认。本站跳转到微信官方授权页面，不自行生成带有登录能力的伪二维码，也不使用非官方中转服务。

## 配置顺序

1. 在微信开放平台完成网站应用和微信登录申请，取得该应用的 AppID 与 AppSecret。
2. 确定本站实际使用的 HTTPS 域名、证书和回调域配置；当前 IP 访问地址不能自动替代已审核的域名。
3. 在服务器受限的运行配置 `/etc/tijing/runtime.env` 配置下列变量。不要将 AppSecret 写入聊天、Git、交付文档或公开发布包。
4. 将 `EXAM_PUBLIC_URL` 设置为实际域名。回调地址必须与它同源，路径固定为 `/api/auth/wechat/callback`。调整访问域名与代理配置时，另行备份并验证旧入口跳转和登录会话。
5. 在官方平台核对回调域与应用状态，再将显式开关 `EXAM_WECHAT_ENABLED=1` 并重启题景服务。
6. 完成以下真实验收后，才对师生公示微信登录可用。

配置模板（占位值不是可用配置）：

```dotenv
EXAM_WECHAT_ENABLED=0
EXAM_WECHAT_APP_ID=填写审核通过的网站应用AppID
EXAM_WECHAT_APP_SECRET=仅在服务器填写真实AppSecret
EXAM_PUBLIC_URL=https://你的已审核域名
EXAM_WECHAT_REDIRECT_URI=https://你的已审核域名/api/auth/wechat/callback
```

没有凭证、显式开关未开启、回调同源校验失败时，界面保留“待开通”状态。公共状态接口不会返回 AppSecret、OpenID 或 UnionID。

## 已实现的流程

- 登录页可从“教师注册”或“学生注册”发起微信授权。未绑定微信首次进入时，需补齐本站登录账号、昵称及备用密码；学生另需班级邀请码。仅验证昵称相同不会自动合并账号。
- 微信已绑定本站账号时，确认后登录原账号，保留原角色，不因从教师入口发起而升级权限。
- 已登录用户在“账号与个性化 → 登录与安全”绑定微信。绑定目标来自已验证会话，回调还需匹配同一会话和浏览器。
- 同一微信身份不可同时绑定两个账号；同一账号不能直接覆盖另一个已有绑定。
- 解除绑定需验证当前本站登录密码，之后仍可使用账号密码。
- state 和注册票据随机生成、单次使用、10 分钟有效，并与 HttpOnly 浏览器 cookie 绑定。账号建立与微信绑定在同一数据库事务中提交。
- AppSecret 仅在服务器与微信官方交换授权码时使用；不保存 OAuth access_token／refresh_token。

## 开启后的真实验收

使用专门测试账号检查：教师扫码注册、学生带班级邀请码扫码注册、绑定已有账号、退出后扫码登录、重复绑定冲突、过期二维码、取消授权、错误回调域、停用账号拒绝登录、解除绑定后密码登录。教师和学生应分别测试桌面及手机环境，并核对平台不接收未绑定浏览器的回调。

合成测试在 `tests/exam-wechat-accounts.test.mjs` 中，通过依赖注入替代微信网络响应；生产服务没有模拟扫码入口或测试身份开关。真实 AppID、域名、凭证就绪前，不将这些测试表述为微信官方验收通过。
