# 题景整卷可视化工作台

> 本文为保留的功能说明，已清理原部署标识。当前版本、安装步骤和导出差异以根目录 README、PROVENANCE.json 及公开部署指南为准；历史验收记录不是本次交付重新执行的结果。

本轮实现“桌面备课 → 单文件课堂讲解与改编”。桌面端读取试卷、校对分题、搭建和组织场景；导出的一个 HTML 文件内嵌题干、题图、场景数据和演示程序，可离线打开、逐题讲解、调参、复制变式，再导出新的完整课件。

## 直接使用

1. 保留 `试卷工作台` 文件夹的全部内容，双击其中的 **试卷工作台.exe**。也可使用发布目录的 **启动试卷工作台.cmd**。
2. 点击“＋ 新建试卷”，输入名称；点击“导入试卷”选择 PDF、DOCX 或图片。一次可选多份资料。
3. 检查“分题候选与原页”：修正题目标题和题干、取消不需要的条目、合并误分条目，点击“导入选中条目”。所有导入题目先标为“待校对”。
4. 在右侧对照原文、公式和题图；“编辑”可修改题干与独立保存的参考解析，目录中的“⋯”可调整顺序、编辑或删除题目，也可修改试卷名称。
5. 点击“＋ 场景”选择现有模板，再按本题条件调整。也可“导入资源”载入旧版平面沙盒 JSON、单场景 JSON 或完整试卷包。一题可保存多个场景，并分别关联小问。
6. 在场景菜单中“复制为变式”；原场景和变式独立保存。核对原题设置后可以“保存为原题基线”，课堂改编后“恢复基线”。保存新的基线需要确认，避免无意覆盖原题。
7. 点击“导出 / 保存”，选择单文件 HTML 上课，或试卷资源包继续备课。课堂只需把 HTML 复制到另一台电脑，用 Edge／Chrome 打开。

“载入专题强化6示例资源”可直接体验：15道题，11道题已有14个场景，其中例4有平面和空间两个场景，练6按小问准备3个场景。其余4道题保留原文，尚未制作可运行场景。示例复用先前制作的课堂预设，所有题目仍标为待校对；演示数值、适用范围和教参练6的条件冲突见原场景说明及 [组合场教学迭代](../USER_GUIDE.md)。

## 文档与扫描件

| 输入 | 本轮处理 | 教师需要核对 |
| --- | --- | --- |
| DOCX | 读取正文、内嵌题图和原生 OMML 公式，按题号生成候选；参考解析与题干分开保存 | 分题边界、公式转换、题图归属、浮动内容的顺序 |
| 有文字层的 PDF | 提取文字、按题号生成候选，并保留原页图像 | 跨栏与跨页顺序、上下标和特殊公式；以原页为准 |
| 图片型 PDF、PNG／JPEG／WebP／TIFF | 保留扫描原页，作为待整理材料；在原页上框选裁题，再填写已确认的条件 | 本轮不自动 OCR，也不补写看不清的题设 |

Word 的旧 `.doc` 格式请先在 Word 中另存为 `.docx`。一次 PDF 最多80页，单个输入文件最多150 MB；长文档可按试卷或章节分开。复杂 PDF 公式的文字提取可能不完整，原页始终可用于对照。

本轮没有接入模型，不会根据导入题干自动生成或判定物理场景。模板只是搭建起点。“已校对”与“已核对”由教师手动标记；调整物理设置后，场景会恢复为待搭建／改编状态。

## 多题、多场景与文件保存

| 文件 | 用途 | 内容 |
| --- | --- | --- |
| `.html` | 复制到课堂电脑直接打开，逐题讲解、改编、再次导出 | 内嵌演示程序、题干、题图和各场景状态；默认折叠参考解析 |
| `.tijingexam` | 导入工作台或课堂 HTML 继续备课 | ZIP 资源包，包含 `paper.json` 与去重后的题图；可包含原始 PDF／DOCX |
| `.json` | 整卷数据备份与导入 | 题目、场景、基线和内嵌图片；不包含演示程序 |
| 单场景 `.json` | 重用某题的一个场景 | 平面或例4空间场景及其观察状态 |

切题和切场景前会暂停并读取当前状态，保存参数、播放时刻、平面视图或空间相机位置。快速连续切换通过独立标记区分，避免把上一题的回复写入下一题。原场景、复制出的变式和原题基线分别保存。

桌面资料自动保存到 **文档\题景试卷\papers**。原始文件和题图与 `paper.json` 分开，元数据按试卷串行原子保存；同一资料目录只运行一个程序实例。点击“本机资料目录”可以备份整个目录。

浏览器不会直接覆盖正在打开的 HTML。课堂修改会另存为浏览器本机草稿；重新打开原文件时，如果存在较新草稿，会提示“继续草稿”或“使用文件中的版本”。要把修改带到其他电脑，必须点击 **导出 / 保存 → 单文件 HTML**，带走新下载的文件。浏览器草稿不可替代文件备份。

整卷导出保留没有场景的题目。资源包内共用的题图只存一份；平面和例4空间演示程序在 HTML 中各内嵌一次，不随题数重复复制。导入 HTML 时只读取资源数据，不执行来源文件的脚本。旧 Agent 项目包可迁移题目与场景，不导入模型会话或账号状态。

## 课堂操作

左侧选择题目，中间切换该题多个场景，右侧对照题干与题图。点击“投屏讲解”扩大画布，通过顶部题目下拉框及前后按钮切题；退出投屏后返回备课视图。场景原有的播放、关键点导航、场和粒子编辑、几何辅助、连续符号依赖仍可使用。空间场景目前只支持已制作的例4模型，不能据此声称支持任意三维物理题。

## 开发与版本

Node.js 24或更新版本；开发与打包目标为 Windows x64。依赖由 `package-lock.json` 固定。

```powershell
npm ci
npm run build:exam
npm run build:exam-sample -- "专题强化6原文.docx"
npm run start:exam
npm run test:exam
npm run check:exam -- --docx="验收资料.docx" --pdf="文字试卷.pdf" --scan="扫描试卷.pdf"
npm run check:exam-html
npm run package:exam -- --out="新的发布目录"
```

打包脚本复制 Electron 运行时及所需本机依赖，输出可移动的完整文件夹；不覆盖已有发布目录。源码位于 `src/exam`、`desktop/exam`，构建、打包和真实浏览器／桌面验收脚本位于 `scripts`。物理计算继续复用现有平面沙盒和例4模型。
