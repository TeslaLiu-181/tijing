# AI 学习助手、资料识别与核验

> 本文为保留的功能说明，已清理原部署标识。当前版本、安装步骤和导出差异以根目录 README、PROVENANCE.json 及公开部署指南为准；历史验收记录不是本次交付重新执行的结果。

本版支持教师统一配置 API，也允许用户配置自己的 API。普通浏览、导入资料和保存资源不会自动调用外部模型；每次 AI 请求都需明确授权，发送范围是当前选中题目、场景、关联对话和显式选择的文件。上传内容中的指令视为资料，不授予模型服务器文件、SQL、Shell、班级名单或其他用户资料访问权。

## 接口与密钥

兼容 HTTPS Chat Completions 基础地址，例如 https://api.deepseek.com/v1。可设置文本模型、视觉模型以及是否使用 JSON response_format。视觉模型留空时尝试文本模型，界面应说明这是配置回退，不能据此声称视觉能力已验证。

教师管理共享连接，用户只管理自己的个人连接。Key 仅保存在服务器 ai-config 私有文件（目录 700、文件 600），不写入 ai_jobs、API 返回、前端持久存储、导出课件或 Git。模型任务创建时冻结当次配置；后续更换 Key 不会改写已创建任务。更换服务 origin 必须重新填写 Key，避免把旧 Key 转发到另一服务。

每次实际请求检查全部 DNS 地址，拒绝本机、私网、链路本地与保留地址；连接固定已验证的 IP，TLS 按原域名验证，拒绝重定向。204/205、非法 HTTP 状态、断流和超大响应都安全返回错误，不使主服务进程崩溃。非 DeepSeek 接口不发送专属 thinking 参数或 image detail=original。

配置与连通测试：
- GET /api/ai/settings：共享/个人连接状态，不返回 Key。
- PUT /api/ai/settings：按权限保存或清除连接。
- POST /api/ai/settings/probe：真实小额请求；vision=true 发送合成红圆/蓝方并检查识别结果。
- GET /api/ai/config：有效模型、来源、能力配置、限制与本人用量。

probe 成功仅代表该合成测试通过；不是全部试题正确性证明。探测计入同一来源预算，另有每分钟与每日上限。

## 预算、并发、取消和恢复

默认每用户每日请求数：学生 30、教师 100；共享全站 300。每日 token 限额：学生 150000、教师 500000、共享全站 2000000。个人 Key 不占共享全站预算，但仍受本人限额、任务策略与平台并发限制。账本按北京时间记录；跨午夜同一 job 的后续预留仍校验和记入 job 原日期，不能借新日期绕过旧日上限。删历史不重置用量。

默认初稿/场景生成上限 16384 输出 tokens、120 秒；独立审校上限 16384 tokens、180 秒；整个任务最多 600 秒。tokens 包含提供商思考消耗，未完成结果不作为答案发布。DeepSeek 辅导、场景与审校请求启用 high 思考；图片/文件提取保持实测便宜模式，probe 显式关闭思考且最多 256 输出 tokens。其他服务采用其自身默认行为。

服务器先保守预留预算，有实际 usage 后结算；已知截断/格式拒绝等失败也计入成本。网络中断、取消或缺 usage 的成本无法精确确认时保留保守预留，不承诺退款。已知使用量和私有初稿/审校审计保留，API 的隐藏 reasoning_content 不保存或展示。

默认最多 2 个执行任务、6 个排队/执行任务；同一用户不能同时运行 job 与 probe。等待配置读取后再次检查关服、并发与任务策略。取消真正终止模型 fetch、PDF/旧版 Word 子进程、DOCX 解析 Worker 和物理 Worker；关服先标 interrupted，再 abort 并等待 finally 清理后关闭数据库。重启不会自动重新收费或重放请求。

服务器环境参数可用于管理员调整边界：
```ini
EXAM_AI_MAX_TOKENS=16384
EXAM_AI_REVIEW_MAX_TOKENS=16384
EXAM_AI_TIMEOUT_MS=120000
EXAM_AI_REVIEW_TIMEOUT_MS=180000
EXAM_AI_JOB_TIMEOUT_MS=600000
EXAM_AI_DAILY_STUDENT=30
EXAM_AI_DAILY_TEACHER=100
EXAM_AI_DAILY_TOTAL=300
EXAM_AI_DAILY_TOKEN_STUDENT=150000
EXAM_AI_DAILY_TOKEN_TEACHER=500000
EXAM_AI_DAILY_TOKEN_TOTAL=2000000
EXAM_AI_PARALLEL=2
```
新接入优先在网页连接设置保存；EXAM_AI_ENV_FILE 为服务器私有环境文件的备用配置入口。可显式设 EXAM_AI_REVIEW_MODEL，但默认审校与当前文本模型相同；个人连接和跨 origin 切换不会沿用不兼容的共享审校模型。图文审校使用有效视觉模型，重新发送本次已授权图片。

## 图片、PDF、Word 与私人原页

每次最多 4 个文件，每文件 12 MB，总输入 24 MB；PDF 每次最多 12 页，合计处理页图 16 张。超页直接要求拆分，没有静默只读前 12 页。同名输入需先重命名以免页号出处混淆。

- 图片由服务器按真实内容解码、限像素、转 PNG 后识别。
- PDF 用 Poppler 提取真实文字层并渲染全部接受的原页；不信任浏览器伪称的 OCR/文字层。
- DOCX 复用安全正文、表格、OMML→LaTeX 与媒体提取。AI 读取的解压、DOM 构建和遍历在独立可终止 Worker 中进行，取消等待 Worker 终止后返回。读取内容展开总量最多 36MB，正文/关系 XML 单项最多 4MB，单次解析最多 15 秒、Worker 老生代堆限制 256MB；堆限制不等于进程 RSS 上限。超量、内存不足或超时会明确拒绝并建议拆分。普通导入/桌面保留现有解析 API 和原有总量限制。超过图数或题图解码失败会标待确认，不把缺图说成完整识别。
- DOC 用 Antiword 读取正文/表格，不执行宏；复杂公式、嵌图与部分旧文件不能可靠读取，会要求补图或另存 DOCX。DOC 正文读取不等于完整视觉识别。

Linux 系统前提：
```sh
sudo env NEEDRESTART_MODE=l DEBIAN_FRONTEND=noninteractive apt-get install --no-install-recommends poppler-utils antiword
```
Windows 的路径包含检查使用系统分隔符；Poppler/Antiword 在 Windows 上尚未完成运行验证。

成功读取的原件和处理页图暂存于 ai-sources 私有目录，最长 24 小时，单 job 缓存最多 64 MB，与个人 500 MB 资源/作业空间共用额度。写入源记录事务内再次校验容量。过期清理与资源修改按同一用户串行；关服等待清理。只有 job owner 能访问源，教师也不能读取学生的私人 AI 原页。

GET /api/ai/jobs/:id/sources 返回 {sources:[{id,kind,name,mime,bytes,sourceName,page,url,expiresAt}]}；kind 为 original/page/image，page 为原 PDF 页号或 null，expiresAt 是毫秒时间戳。
GET/HEAD /api/ai/jobs/:id/sources/:sourceId 返回认证源文件；原文档下载，页图用于对照。过期或迁入资源后旧缓存 URL 返回不可用。

明确 apply 后，原件保存到私人 paper.sources.asset，处理图保存到 paper.assets，可靠匹配的题图保存到 question.attachments，页号保存到 sourceAnchors。PDF 以 sourceName+page 为主，不让装饰性 imageName 拼写差异否决正确页号。无法对应多页时保留全部私人来源索引，但不把整份 PDF 或解析页静默附到单题；题目标待人工对应。

资源资产、源缓存引用消耗和 job.applied 标记在同一事务内完成。失败可重试 apply，不再次调用模型；源文件在资源 commit 成功前保留。删 AI 历史不删除已经迁入的私人资源。过期源会拒绝 apply，避免静默丢图。

## 场景生成与真实物理核验

当前自动生成支持原生平面沙盒。选择三维 example4 后请求自动场景生成会在模型调用前拒绝；三维手动编辑与文字答疑仍可用，三维 AI 答疑不宣称已程序核验。

模型先列 givens、assumptions、missing；不清图、未知符号/方向/单位/边界先待确认，不能补造题设。结构化提案不接受可执行 JS 或外部几何应用。关键质量、电荷、速度、位置与场域参数不可静默套默认值。

核验真实调用：
1. 原生 schema/量纲/关系解析：循环、非法单位、无效交点和缺失引用都会阻挡。
2. 真实轨迹、速度、受力、动能与边界事件读回；截断/非有限数值阻挡。
3. 磁场力与速度正交、纯磁场能量不变；独立复合 Simpson 电功积分与动能变化对照。积分最多前 60 段，明确为有限采样证据。
4. 有自由参数时最多 3 个参数各扰动 1%，读回定义属性和轨迹变化，基线保持不变；这不证明所有参数范围。
5. 部分明确来源硬条件检查：数值单位、单粒子电荷/单场方向、明确单电子/质子常数与提案的矛盾。否定、假设、OCR 疑问和多粒子不盲套物种常数；没有适用规则不代表原题语义已验证。

零期望值检查使用服务器按指标与真实物理量尺度给的舍入容差：位置/速度按运动尺度，力按实际电场力/磁场力尺度，能量与功率按对应量值尺度；检查表记录有效容差。模型 absoluteTolerance 不参与实际放宽，不能用大通用绝对误差掩盖错力。

核验失败至多一次修正，再失败不能 apply。二次修正仍执行原指标、时刻、粒子 trace 与期望值；不得删除、移动或放宽检查来过关，可添加或收紧。原提交检查、每次真实读数与范围变化均保留；范围被改变时阻断自动应用并要求明确重建请求。场景最终核验文案由服务器生成，模型对工程容差的未经核对解释仅作私有审计，不当教学答案。

用户对照原题确认条件、接受演示假设并通过 CAS 后创建独立 draft 场景，保留原场景与基线；不自动标教师已核对。首页无资源时也可新建私人待校对探究，保留原请求与模型整理条件/假设。

原生 Worker 默认内存 96 MB、单次 12 秒。native_scene_checked 只表示结构化模型核验，不是所有原题语义正确性证明。自由中文 regex “可信答案”快捷替换已移除；规范化工具探针只在明确结构化模型条件下使用，标签 explicit_model_probe、sourceVerified:false，未接到自动文本答案。

## 辅导、独立审校和仅提示策略

普通 tutor/review 流程为初稿→独立审校→最终结果，依据选中原生场景真实数据（若支持）检查条件、量纲、方向、边界、结论/推导一致性。图文审校再次使用本次授权图片。修正结果与初稿审计区分保存，不展示未审原稿作为最终答疑。

原稿 missing 保留并与审校 missing 合并，不能因 supported 自信消失。待确认结果的后续入口统一要求补齐缺失条件，避免“只补其中一项就一定能判断”的过度断言。

公开 review 为 {verdict,model,issues,limitations,verification,imageSourceReviewed,imageSourceVerified,hintsOnly}。verdict 为 supported/corrected/uncertain；imageSourceReviewed 说明实际是否再次收到图，imageSourceVerified=false 明确不将 AI 看图冒充原图已被独立证明。model_reviewed 表示二次 AI 审校，不是程序证明。

教师任务策略 allowed/hints/disabled 在入队、实际调用、修正/审校与 apply 时复查。关联私人原稿或历史追问可由服务器反查任务，省略 assignmentId 或自带个人 Key 不能绕过。任务本身的版本/策略变更阻挡旧任务上下文。

hints 审校必须返回短 nextStep+question，服务器组合提示并拒绝明显完整答案合同；学生 DTO 不返回完整初稿、审校可能含答案的 issue、模型自拟额外条件或详细求解读数。此规则限制平台内自动成品输出，不宣称能阻止所有考试作弊或外部 AI 使用。

## API 与验证

POST /api/ai/jobs 输入 {mode,prompt,consent:true,resourceId?,questionId?,sceneId?,view?,assignmentId?,followupTo?,attachments?:[{filename,data}]}。
模式 tutor/scene/extract/review。GET 列表/单 job 是本人记录；POST /:id/cancel 真实中断，DELETE /:id 删除本人历史。
POST /:id/apply：场景 {version?,confirmGivens:true,acceptAssumptions:true,title?}；识别 {version?,confirmGivens:true,questionIndices:[0,2]}。候选题干与页图均保持 pending 校对。

场景内 AI 侧栏与独立 AI 页使用同一个面板实例；折叠不清草稿、附件或运行任务，打开本身不暂停/保存画布。发送时冻结选中的题目/场景 ID 与附件，服务端读取已保存内容。手动切画布只提示来源不同，需显式“使用当前场景”；本轮任务仍绑定原来源。浏览旧历史不能绕过同用户已有运行任务。场景应用由编辑器排队保存、短暂冻结、最新版本 CAS 与不再回存旧稿的载入完成；成功后明确把下一轮问题指向新变式并重新确认发送。原结果标签仍属于原提问。

同一浏览器的不同标签页切换账号时，通过同源会话通知立即清除旧私有界面并使在途回调失效；同账号重登同步 CSRF，保留草稿。应用响应写入本地编辑状态前，还会通过 /api/me 核对实际 Cookie 身份，避免未收到通知时迟到的旧提案重新显示。

新 job 的 uiContext 只记录服务端授权读取的资源/题/场景标题、查看范围和本人的 followupTo 父记录 ID；旧记录缺少这些信息时明示不可得，不从回答猜测。追问只把选定上一轮的请求和回复带入模型，不宣称发送全部可见聊天历史。

新提案在本人完整私人稿保存私有 paper-content/1 内容指纹，应用仍必须提交并匹配最新资源 version，复核当前任务权限/策略和原题/场景存在。内容指纹覆盖整份资源，只排除 activeQuestionId/revision/updatedAt、题目的 activeSceneId/updatedAt、场景 updatedAt、snapshot.context/baseline.context 观察状态，以及资产元数据的 url/displayURL。单纯播放/暂停、视角/窗口或切换选中题不会使内容冲突；正文/解析/notes/review、所有物理场景和基线、题图标识/页号/路径/hash 等内容变化仍拒绝。指纹不在 DTO 或模型资料中返回。旧提案、共享/工坊快照沿用严格原版本与原场景 hash 保护；源已删除的新私人提案不能当成无来源任务另存。409 的具体原因按服务端提示呈现。

确定性/模拟提供商测试验证权限、缓存、预算、失败、关服、条件门槛、格式与原生物理实现；不能作为实际模型答题正确性证据。
真实脚本 ai-live-check、ai-service-live-check、ai-quality-check 只用合成材料，不读真实学生资料；.qa 证据不随源码发布。

已发现并保留的真实失败：非思考初稿会在半平面/条带方向、边界与电功表述上出错；二次模型审校也可能支持错误或新增不严谨尾句。8192 初稿/审校曾截断，随后按真实失败增加分层预算。最新 half-plane 主体与 strip 主体人工核对正确；三倍速度 held-out 核心半径/穿越/高度/速度角度与独立原生参考一致，但尾部泛化提醒仍有错误，不能记“全文正确”。缺条件案例门槛保持，但曾有过度肯定 follow-up，已规范化输出。上述结果不能推导普遍正确率。

教学应继续使用原页对照、条件确认、演示假设承认和教师复核。实际提供商调用与 mock、结构化模型自洽与原题语义、AI 审校与数学证明必须分别报告。

官方依据：[DeepSeek Vision](https://api-docs.deepseek.com/guides/vision/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 2026-10-04 Agent 工作台扩展

答疑和场景请求可实际调用选中场景工具：读取对象、查询运动/受力/动能、查询共享时间轴事件、求值原生关系、检索本轮选中的资料；场景模式另可试算临时提案。工具调用限制在本轮授权资料，不能执行任意代码或获取未选择的资源。最多五轮，每轮最多六个工具请求；原生计算使用可终止 Worker。工具输入、结果和错误作为证据记录，模型随后收到同一真实结果继续作答。

模型响应支持 SSE 流式接收，并显示实际处理阶段、工具调用和耗时；进度中的“已接收字数”不是已完成的教学答复。隐藏 reasoning 内容仅用于模型协议所需的临时续接，不写入公开活动记录。中断后的活动不会持续显示假运行状态；已经收到的可靠使用量保留，缺失使用量不伪造为零。

历史按探究串联，重新打开可看到自己的前后轮；模型上下文最多取最近 12 轮、约 32,000 字符，并在截断单轮时标记。接口返回的链最多 32 轮。每轮继续绑定自己提交时的资源与场景，不随页面后来选中的题目暗中切换来源。

运动工具结果显示时间、位置、速度分量与动能；关键事件使用实际名称、轨道和时刻，原始 JSON 放在次级折叠。完成请求保存本轮原生源快照 `result.sourcePreview`。点击读数或“回看本轮场景”在只读副本中定位，即使当前编辑稿后来改变，回看仍对应原工具的输入，不改当前稿或资源版本。该副本是请求时的来源，不称“已核验候选”。旧记录若没有来源快照，保留原答复和读数，但不伪造回看入口。

已保存来源按原生存档最多 500 个对象读取；新生成提案仍为最多 60 个对象、120 个粒子。单轨运动查询保持完整场/几何依赖，不把多粒子源改成一粒子以假装查询；默认读第一条，也可指定准确 `traceId`。超过 24 条轨道时，来源审计明确给出已读、总数、未读与时间范围，并返回 `partial:true`、`passed:false`；这与求解器截断是两种不同状态。大源的事件查询要求指定轨道。不能把“部分范围未发现违例”写成全场景已经通过。

新提案显示几何、物理参数、持续定义和观察时长的变化；不把求解器的交点连续性缓存当成用户改动。生成结果仍须确认题设和演示假设后保存为独立变式。拖动对象标注使用像素偏移，不改变物理参数；该显示属性不会让新私人提案仅因整理标注而失效，文字、坐标、题干、基线物理量及附件身份继续参与内容保护。

学生仅提示任务的公开 DTO 不包含工具输入/结果、完整初稿或来源回看快照。该策略与个人/共享 API 配置无关。手写公式走独立、明确确认的笔迹通道，详见[图形公式与手写识别](图形公式与手写识别.md)。

本轮真实提供商验收只用了合成材料：一次答疑实际调用原生工具并经过独立审校，3 次模型调用、21,391 tokens；两张合成笔迹识别共 2 次调用、1,492 tokens。第二张候选保留了下标 0/字母 o 的歧义，不能记为完美转录。这些小样本用于确认链路，不代表普遍答题或 OCR 准确率。其余界面流程使用明确标记的本机模拟提供商，未发送真实学生数据。
