# 师生账号与个性化

> 本文为保留的功能说明，已清理原部署标识。当前版本、安装步骤和导出差异以根目录 README、PROVENANCE.json 及公开部署指南为准；历史验收记录不是本次交付重新执行的结果。

v0.7.0 将账号扩展为“平台管理员、教师、学生”三个权限范围，继续使用现有登录账号、密码、班级和资源。账号中心从右上角账号菜单的“账号与个性化”进入，沙盒工作台的更多菜单也提供同一入口。

## 教师与学生开户

教师在登录页选择“教师注册”，填写登录账号、昵称和密码，即可建立独立教学空间。教师注册不使用学生邀请码，也不会获得平台管理权限。

教师进入“班级与小组”创建行政班，向学生提供该班的邀请码。学生在“学生注册”中填写邀请码，注册后归属该班。学习小组由教师选择自己管理的学生组建，可跨自己管理的行政班组合。保留原来的“一名学生一个行政班、可加入多个学习小组”规则。

不同教师只能查看和管理自己负责的班级、小组及学生名单。资源接口继续校验资源所有者，教师身份本身不授予读取学生私人原稿的权限。负责教师重置学生密码后，学生应重新登录并修改为自己的密码。公开社区和公开工坊仍面向已登录的平台用户；公开不等于允许任意教师代替作者修改或撤下内容。

升级时，原学习空间的负责教师成为平台管理员；新注册教师没有该标记。平台管理员的账号中心额外显示“教师管理”，可查看教师列表、停用／恢复教师账号、重置普通教师的密码。平台管理员不能通过这个界面停用或重置自己，也不能读取其他教师的 API 密钥。

停用教师会结束其现有登录会话，禁止再次登录，并使其教学连接不再接受新请求；保留其班级、资料和已公开内容。已开始的 AI 请求按原请求生命周期完成或由用户取消。学生密码／登录权限由行政班负责教师或平台管理员管理，单纯的小组成员关系不授予控制学生账号的权限。

## 模型连接的分配

教师打开“API 连接设置”，在“我的教学连接”中选择：

- **我的默认教学连接**：作为名下班级和小组的默认服务。
- **某个行政班或学习小组**：初始继承默认连接；填写并保存后成为该范围的专属连接。其成员才能使用。
- **恢复继承默认教学连接**：移除专属配置，重新跟随教师默认连接。

每个范围可分别设置 API 基础地址、对话模型、视觉模型和密钥。清除某范围的密钥会让该范围暂时不可用；专属配置未删除时，不会悄悄回退到另一密钥。切换服务商地址时必须同时提供新的密钥，以免把原密钥发送给另一服务。

学生可在“我的使用方式”选择所属班级或小组提供的教学连接，也可继续使用自己的个人 API。浏览器只能得到连接状态和模型信息，无法读取教师密钥。退出小组、班级归属改变或教师被停用后，原选择不可再用于新请求，需要重新选择有效连接。

密钥保存在生产数据目录的 `ai-config/` 私密文件中，文件权限 600、目录 700。原全站共享配置只迁移给原负责教师；其他教师从未配置状态开始。旧 `shared.json` 保留用于受控回退，但新版不再将它作为全站共享来源。

现有平台级并发、每日请求数和 token 上限继续生效；本版未增加充值或按班独立计费。保存连接不会调用模型，“测试连接”会发送界面已说明的模型请求。个人 API 仍不能绕过学习任务中“禁止 AI”或“仅提示”等规则。

## 个人资料与图片

师生均可设置：昵称、个人签名、简介、学科、学段／年级、最多 8 个兴趣课题标签，以及 5 种主页主题色。登录账号保持不变，昵称可修改。

头像和背景图接受静态 JPG、PNG、WebP，单张最多 4 MB。服务器重新解码、裁剪／缩放并编码为 WebP，不原样提供上传文件，也不保留 EXIF 信息。头像为正方形；背景可调整显示位置。图片上传后先预览，点击“保存个人资料”后才用于主页，可恢复默认头像或主题背景。

个人资料和已保存头像／背景对平台内已登录用户可见。资料不是实名档案，不要求填写真实姓名、电话或其他联系方式。更换昵称和头像后，右上角账号及社区、工坊作者展示会使用新资料。未保存图片仅本人可预览；其他用户不能把该图片编号用于自己的资料。

资料保存带版本检查：两个页面同时编辑时，旧页面不能直接覆盖新保存内容。离开前有未保存修改会提示。

## 微信登录状态

“登录与安全”中可以查看微信绑定状态。未配置官方应用时显示“待开通”，账号密码功能照常使用。接入方法及真实联调要求见 [微信登录接入说明](微信登录接入说明.md)。

## 维护入口

| 文件 | 职责 |
| --- | --- |
| `server/exam/auth.mjs` | 师生注册、会话、平台管理员与账号管理 |
| `server/exam/account-permissions.mjs` | 平台管理与学生账号控制边界 |
| `server/exam/account-profiles.mjs` | 资料版本、图片解码和访问权限 |
| `server/exam/ai-settings.mjs` | 教师默认连接、班组覆盖、学生来源选择与迁移 |
| `server/exam/wechat-accounts.mjs` | 微信 state、浏览器绑定、注册／绑定事务 |
| `src/exam/web-account-center.mjs`、`.css` | 账号中心与响应式布局 |
| `src/exam/web-ai-settings.mjs` | 教学范围与连接配置界面 |

账号、图片、授权和密钥都在服务器持久数据中，不放入发布包或版本库。不要把生产数据复制到普通源码目录。
