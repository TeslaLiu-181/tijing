# 原生动态几何与区域场

> 本文为保留的功能说明，已清理原部署标识。当前版本、安装步骤和导出差异以根目录 README、PROVENANCE.json 及公开部署指南为准；历史验收记录不是本次交付重新执行的结果。

这轮在现有原生沙盒扩展，未嵌入 GeoGebra runtime。几何核为自行实现的点、线、圆与简单多边形运算，继续由原生解析运动求解器计算粒子；不是静态描边或只生成提示词。

## 构造与保存

`scene.objects` 新增 `kind: polygon`；几何对象可带 `construction: {type, inputs:[稳定对象ID], group?, branch?, pathUnit?, memory?, permutation?}`。坐标及半径/顶点缓存仍为厘米，数学量在关系求解器内部用 SI。旧对象的 `defs` 接口保持可用。结构由 `geometryToolSchema()` 和 `constructionSpecs` 读取。

当前 33 个工具：自由点、路径点、中点、定比分点、极坐标点、垂足、交点、圆心、派生顶点；两点直线/线段/射线、定长线段、定角射线、平行线、垂线、垂直平分线、角平分线、派生边、点到圆的成对切线；圆心半径圆、圆心圆上点圆、三点圆、圆规圆；简单多边形（含凹多边形）、正多边形、三点矩形、三点平行四边形；整图形的旋转、沿有向线段平移、轴对称、中心对称与中心缩放。多边形最多 64 顶点。三点矩形以 AB 为第一边，把第三控制点投影到 AB 的法向确定高度；第三点不必是矩形顶点。平行四边形输入的是连续的前三顶点。路径点：直线/线段/射线参数无量纲，圆参数为度，多边形参数为边序号加边内比例。点只在自由或路径参数可变时直接拖动，其余应拖自由输入或修改构造。

`addConstruction(scene,{tool,inputs,position?,radius?,radiusExpr?,parameter?,branch?,length?,lengthExpr?,angle?,angleExpr?,factor?,factorExpr?,count?,countExpr?,orientation?,index?,indexExpr?})` 返回 `createdIds/primaryId/objects`。输入都是稳定 ID，重命名不改依赖。`moveConstructionPoint` 返回 `moved/reason/parameter`。`constructionOwns` 标识构造控制的坐标与端点，不能另写同字段 `defs`。构造核与点击工具使用相同输入类型契约；错误类型的存档或提案不会偷偷取其中心当作合法点。

`ensureGeometryFeature(scene,ownerId,'vertex'|'edge',index)` 以 1 起序号取得稳定的 `vertex-point` / `edge-line` 别名 ID，可继续参与圆、交点、垂线等构造。派生多边形的缓存顶点不被复制成自由点；别名通过 `inputs:[polygonID]` 持续取实际顶点或有限边，`index` 可由无量纲 `defs.index` 控制。边数变少导致序号不存在时别名和下游无定义，边数恢复后原 ID 恢复。旋转角单位 deg，平移倍数无量纲，正多边形边数为 3–64 整数，方向 `construction.orientation` 为 ±1。

多边形的 `area/perimeter` 是只读派生量（分别 cm²/cm），可在表达式中引用或调用 `area()/perimeter()`，不能另写同字段定义。直接懒引用也会先重建完整顶点集，不能误用改变边数前的缓存。

无定义与对象删除分开。退化线、共线三点圆、无交点、自交/零面积多边形保留对象 ID 和最后有限数值；`_defined/_error` 是派生状态，不应显示旧数值为当前有效结果。输入恢复后，同一对象重新定义。交点成对共享 `group`，先做最小总距离配对；切触不丢掉上次非重合锚点，有限路径的数学交点坐标也保留于连续性记录。切线在圆外返回两条直线，圆上保留两条重合切线身份，圆内两条无定义；保存旧接触点用于恢复配对。无实根区间后的匹配是明确的近邻恢复规则，并非任意拓扑变化的数学唯一延拓。

## 直接比例、极坐标与定长约束

五个常用直接约束复用现有 point/line/circle 与稳定输入 ID：

- `ratio-point`：`inputs:[A,B]`，`factor/defs.factor` 为有向比例 λ，缺省 0.5、无量纲。P = A + λ(B−A)，λ<0 或 >1 是外分；A/B 重合时按该仿射式连续延拓为 A，而不声称此时零长度的字面比值有定义。
- `polar-point`：`inputs:[O]`，`length/defs.length` 为极径 r（缺省 1 cm，允许 0），`angle/defs.angle` 为全局 +x 逆时针方向 θ（缺省 0°）。r=0 时 P=O，方向仍保留，距离恢复后继续有效。
- `fixed-segment`：`inputs:[A,B]`，`length/defs.length` 为长度 L（缺省 2 cm，必须正）。输出有限 segment，从 A 沿 B−A 方向取长 L；A=B 时方向无定义，保留线段 ID/定义/最后有限缓存，方向点恢复后同对象重新定义。

- `fixed-angle-ray`：`inputs:[A,B]`，`angle/defs.angle` 为相对 AB 的逆时针有向角 θ（缺省 45°，允许负值），输出从 A 出发的 ray。它区别于相对全局 +x 的极坐标角；A=B 时方向暂未定义，恢复后身份不变。
- `compass-circle`：`inputs:[C,A,B]`，以 C 为圆心、AB 长度为半径；圆心与半径均由输入持续控制。A=B 时圆暂未定义，不能把上次半径当当前值。

创建入口使用 `factorExpr/lengthExpr/angleExpr` 安装连续表达式；图形公式、重选输入和整对象变换使用同一 schema。普通自由点和自由线不会显示这些工具专属的“长度”参数；几何长度仍可用 `length(line)`、`distance()` 等真实测量表达式引用。极径/定长可引用 m 或 cm 参数，内部 SI、画布 cm；比例 λ 不会被错误赋予长度单位。

新点可继续作为多边形/圆的输入，定长线段端点可用 `end(line,2)` 持续引用。几何变动通过原有 `regionSource` 传到场边界并重算真实轨迹，场强与方向不自动变化。方向或维度关系无定义时，相关场暂停而不假画自由飞行。

## 整对象持续变换

`rotate/translate/reflect-line/reflect-point/dilate` 的第一输入是 `inputKinds: geometry`，只接受原生 `point/line/circle/polygon`；输出一个相同 kind 的派生对象，`construction.inputs` 持续引用源与中心、向量或轴，不复制自由点。工具 schema 声明 `outputKind: input0` 和四种 `outputKinds`，输出类型随创建时的源类型确定。重选源必须保持同 kind；不能把已有圆 ID 偷换成多边形，破坏它的场绑定。第二输入镜像轴仍可使用坐标轴/直线/直尺，平移需要有向线段。

旋转角 `angle/defs.angle` 单位 deg；平移和中心缩放 `factor/defs.factor` 无量纲。负倍数允许。中心缩放为 `center + factor * (point - center)`：0 倍时点仍有定义，线、圆和多边形退化而无定义；保留 ID、定义和最后有限缓存，改回非零后恢复。圆的半径按缩放倍数绝对值变化，旋转/平移/对称保持半径；线保留源的 line/ray/segment 范围；反射不倒排顶点数组，因此顶点与边别名仍按同序号引用映射后的几何。

圆的圆心/半径、线的端点/lineType、多边形的顶点都由变换控制，不能再定义同输出字段。源、中心、向量、轴或参数改变时输出及绑定场继续更新；源暂时无定义时下游同样无定义，条件恢复后身份不变。

先变换几何，再填电场或磁场。`regionSource` 让场边界跟随图形，但场强、电场方向、时间规律和粒子初态不会自动旋转、平移或缩放；教师要改变这些物理量时另行定义。直接变换 field/electric、粒子、粒子源、直尺或坐标轴不在此接口范围。

示例 `geometry-transform-fields`：alpha 参数从 0° 改为 45°，整个矩形几何和绑定电场区域一起转动。演示质子以 `1e5 m/s` 从 `(-3,0) cm` 沿 +x 射入，`E=0.5 kV/m` 仍沿 +x；真实出口 x 从 1 cm 变为 `sqrt(1/2) cm`，场与粒子 ID 不变。这是选定演示参数的数值联动，不把几何变换当作物理量的自动变换。

## 重选已有构造输入

`redefineConstruction(scene,id,{inputs})` 只更改输入 ID，不改工具类型、对象 ID、名称/显示、构造参数和 `defs`。成对交点或切线按照现有 type/group/输入对整体修改，保留 branch 与连续性记录；绑定的区域场和下游仍引用原输出 ID。

返回 `{primaryId,changedIds,defined,states:[{id,defined,message}],issues,fieldUnavailable,resolution}`。`defined` 只表示选中的原对象；`states` 给出同组每个输出状态。计算在场景 clone 完成，类型、结构或循环错误时原场景完全不变；成功后替换场景内容，因此调用方应按 ID 重新取对象，不缓存旧 JS 对象引用。`resolution` 可复用计算结果，`changedIds` 是重选的输出组，不代表只有这些对象的读数发生变化。

新输入应符合相同工具的 typed 输入规格。纯构造/区域引用环即使被另一无定义输入遮住也会拒绝；数学属性环使用原生属性求值诊断，独立属性之间的对象图回边不会一概判为循环。合法输入暂时无交点、圆内点无切线或派生序号不存在，会返回 `defined:false` 和具体消息，保留输出与下游身份，不当作输入错误撤回。

路径点保留参数的数值与定义。圆路径的角度参数不能静默改作线/多边形的无量纲参数：这种跨单位重选明确拒绝，需要另建路径点并确认参数。同类路径可直接重选。`redefineConstruction` 对手工多边形只重选相同数量顶点；插入/删除/重排使用下节专门的列表编辑入口。顶点/边别名仍是序号语义；将它重选到另一多边形时 `index` 不变，越界无定义，恢复后同 ID 可继续使用。

聚焦验证包含：圆半径参数与 E 场/粒子真实进出口联动、交点与切线成对修改/恢复、失败时完整 JSON 不变、自环/间接环与被无定义遮住的构造环、合法的独立属性回边、路径参数单位及序号别名重选。

## 手工多边形顶点列表

`editPolygonVertices(scene,id,{inputs})` 编辑 `construction.type: polygon` 的完整有序点 ID 列表，`{points}` 编辑没有构造的自由多边形完整厘米坐标列表。两种输入不能混用；手工 ID 列表末尾重复首点会规范化闭合，实际顶点需 3–64 个。派生正多边形、矩形、平行四边形仍用自身参数或重选输入，不能改成自由缓存坐标。

输出与重选接口相同，保留 polygon、场的 `regionSource`、对象 ID、所有原 `defs`，不创造替代场。错误类型、缺失 ID、过多/过少顶点、非有限坐标或循环时原场景不变。自交、重合边或零面积按既有无定义规则保留原身份、给出消息并暂停相应场，恢复有效列表后继续计算。

现有 `vertex-point/edge-line` 的 `index` 及 `defs.index` 不迁移：插入或重排后，第 N 个引用新列表的第 N 个；缩减后越界别名暂时无定义，顶点数恢复后同 ID 恢复。自由多边形的坐标 `defs.pointN/pointNx/pointNy` 仍覆盖同序号的数值；若删减后这些定义目标不存在，编辑会拒绝并提示先解除，不能偷偷丢掉定义。

拓扑验证包括三角形增为四边形后的实际场出口、重排后的序号引用、自由坐标定义继续联动、缩减定义目标拒绝、自交/退化及越界别名恢复。

## 真正的区域场

`fillRegion(scene,regionId, field|electric, {B?,E0?,fieldAngle?,waveform?,period?,phase?})` 创建带 `regionSource` 的新场。圆对应 `shape: circle`，多边形对应 `shape: polygon`；场强与时间规律独立，边界连续依赖原区域。隐藏几何不解除场绑定。不可另改绑定场的几何尺寸或坐标。

简单凹多边形使用完整多边形的点归属和有限边，不用所有半平面相交误当内部。运动仍采用真实边界事件、解析 Lorentz 段和单侧归属。平滑边切触按法向速度/曲率判定，凹顶点用局部出射方向判定。区域无定义时，已启用场禁止用假自由飞行替代。

## 同心环形电场与磁场

`field/electric` 新增 `shape: annulus`，使用同一圆心 `(x,y)`、外半径 `radius` 和内半径 `innerRadius`，单位均为 cm。`0 <= innerRadius < radius` 时场域是两圆之间的环带；内孔不贡献这个场，若另有重叠场仍按原有叠加规则计算。内半径为 0 时完全退化为圆形场域，不保留虚假的中心边界。

半径都可由 `defs` 持续控制。非负且有限的内半径大于等于外半径时，保留真实输入、对象 ID 和定义，标记几何暂未定义并暂停相关仿真；存档重开仍可恢复，不用旧半径继续演算。负数、非有限数和错误量纲沿用原数值检查。AI 提案必须明确提供两半径，不能把 UI 创建默认值当作题设。环形不接受单一 `regionSource` 冒充完整区域；可分别用公式引用圆心、外半径和内半径。

`area(环形场)` 为 π(R²−r²)，`perimeter(环形场)` 为两条周界总长 2π(R+r)；无效环域不返回负面积或旧缓存。整环不是一条路径，不能直接作 `on`、`intersect` 或 `vertex/edge` 的单曲线输入；应明确选择 `circle(pos(o4),o4.radius)` 或 `circle(pos(o4),o4.innerRadius)`。零内半径不提供内圆。内外圆边界分别参与真实事件计算，内边界的单侧法向与外边界相反。

示例 `annular-electric` 使用演示值 R=2 cm、r=1 cm、E=2 kV/m 沿 +x、m=1 u、q=+e，粒子从 (-3,0) cm 以 10⁵ m/s 沿 +x 出发。在 0.6 μs 内，两次穿过环带共获电场功 40 eV，中间内孔段合力为零、匀速直线运动；r=0 时该示例电功为 80 eV。这些是所列演示参数的原生读回，不推广为任意轨迹的恒定电功。

切换场域形状保留当前已解析中心、场强、方向、时间规律与对象身份，移除新形状不适用的端点或内半径定义；完整旧状态可一次撤销恢复。其他公式若仍引用已移除的几何量，会明确显示暂未定义，需修改公式或撤销；不会自动删掉场强公式或用旧半径假装关系仍有效。

## 依赖更新与桥接

`resolveScene(scene,{changedIds?})` 保留 `issues/fieldUnavailable/scene`，新增 `dependencyGraph`：`nodes{id,label,kind,defined,algorithm,inputs,message}`、`edges{from,to,type}`、`order/dirty/evaluated/physicsDirty`。`buildDependencyGraph(scene)` 读取相同解析关系。图是对象层聚合；真正循环由属性求值栈判断，同一对象自由坐标引用或不同自由坐标的互引用不能泛化为错误。

变更 ID 沿下游传播，原定义结构改变时完整重算。`inheritResolverState(source,candidate)` 显式继承已解析场景的纯值缓存给其 clone；随后调用带 `changedIds` 的求解，才能在每帧 clone 的编辑器中获得实际增量效果。不继承也保持正确性，但不宣称增量收益。

代表性示例：`geometry-l-region` 的参数 d 持续控制凹口与 E 场/粒子出口；`geometry-intersections` 的参数 h 使线圆交点区域经历有效、切触/无解、恢复，场身份不变。定向测试覆盖构造联动、无定义恢复/存档、真正凹区域运动、凹顶点穿越、沿边起步、内外切触与克隆增量隔离。

## 公式标注与提案

`kind: label` 可保存 4000 字符公式，字号 10–72 px、框宽 80–1200 px、框高 40–600 px；其它对象名称仍限 60 字符。`labelVisible` 只控制该对象标注，不改物理量。编辑与渲染由原生 UI 处理。AI `sceneSchema/buildScene` 暴露同一构造字段；自由几何坐标、构造半径/角/倍数/边数/序号、路径点参数须显式提供，场边界可从 `regionSource` 读回，不能静默补题设。
