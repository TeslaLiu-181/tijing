05 / Know the boundaries

分享源码，也把边界说明白

复用项目时，区分可公开的代码、实例私有的数据，以及需要单独配置的外部服务。

代码与教学材料

项目代码采用 MIT 许可证。教学材料与第三方依赖应按各自的授权或许可说明使用。

  • 教材与历史教学材料已由提供者确认可再分发。
  • 材料的详细来源、署名与授权信息仍待补充。
  • 阅读 LICENSE 与 ASSET_LICENSES.md，不要把所有素材视为 MIT。

实例数据与账号

公开仓库与个人部署实例应分开。账号、班组关系和附件属于实际使用产生的数据。

  • 真实数据库、会话、账号资料与上传附件不随源码发布。
  • 头像、背景、简介和兴趣标签由用户在实例内维护。
  • 备份与迁移须同时考虑 SQLite 和持久附件。

密钥与外部服务

模型 API 和微信开放平台均需部署者自行配置，示例配置不能替代真实凭据。

  • API Key、AppSecret 和服务器凭据留在实例配置中。
  • 教师独立管理教学 API，访问控制由服务端执行。
  • 公开部署前阅读 部署指南 中的环境与运行要求。
微信扫码现在是否可以直接使用？

接入代码已经预留，但默认关闭。正式启用需要微信开放平台审核通过的网站应用、可配置回调的域名及正确凭据。仅复制项目或部署到 IP 地址，不等于已具备微信扫码注册条件。

AI 能为所有沙盒自动建模吗？

目前自动建模只覆盖原生平面场景。AI 输出作为候选，仍需经过原生工具校验和用户确认。其他既有沙盒模块不应被描述为已支持同等的自动建模能力。

教师、学生与班组是什么关系？

教师可自助注册独立教学空间，管理自己的班级、小组与教学 API。学生采用单行政班、多学习小组的关系。平台管理员负责平台级管理，具体授权规则以服务端实现为准。

离线导览、离线导出与完整系统有何区别？

本页是无需服务端的离线文档。场景离线导出用于携带教学内容。完整的账号、班组、持久化与 AI 服务仍需运行 Node.js 服务端；AI 调用还需要可用的外部模型接口。
