本次以 2026-10-14 实际核对的上游 **v0.7.0** 为基线。服务器源码、Git 标签和运行清单都指向 `e98b3f2395d91f90a224235ff840998cb13e8f1b`；运行清单的 262 个文件未发现缺失或内容偏差。

## 本次公开化调整

1. 把根包的历史工程名及旧工程版本改为 `tijing` / `0.7.0`，声明 Node 24.14–24.x；不升级依赖版本。
2. Web 和桌面运行包从更新记录取产品版号；源码 ZIP 没有 Git 时，从溯源文件记录来源，不误读外层无关仓库。
3. 默认 `npm run build` 指向 Web；源码启动和初始化显式读取根 `.env`。历史独立演示构建保留为独立命令。
4. 增加三个原创、无附件的入门任务，构建时自动生成。原专题 DOCX 示例生成器保留为 `build:textbook-sample`。
5. 保留用户已确认可再分发的题图、题目、答案、参数化场景和制作脚本；三个本机绝对来源目录改为 `--source-dir` 参数。
6. 保留可读的教学功能手册，清理原部署标识；重写 README、架构、部署、开发、Agent 与可视化导览。
7. 增加 MIT、独立教学材料登记、锁定依赖许可表和文件清单。

物理模型、账号权限、数据库结构、教师 API 选择、微信开关和原生沙盒协议没有因本次公开化整理而改写。界面仅把默认样例入口名称改成“体验入门示例”。

## 未进入公开包的内容

原部署的 `.env`、外置秘密配置、数据库、会话、用户上传的头像／背景／附件、备份、日志、依赖目录、`.qa`、研究缓存及旧生成 HTML 均未进入源码包。原 Git 历史和私有运维交接记录也未复制。

公开包不是生产站点备份，启动后会创建自己的数据。已有教学资产不是学生上传文件；材料独立授权与 MIT 范围见 [资产说明](../ASSET_LICENSES.md)。

## 本轮验证边界

本轮核对版本、快照、保留资产和依赖元数据；对公开导出的文件进行敏感文件、路径、UTF-8、本地链接与清单检查，并验证公开构建入口。它不是新一轮师生业务功能验收，不重跑所有业务测试，不调用真实模型或真实微信授权。

最终交付检查结果写入交付目录的验收说明；文档内保留的旧测试数量属于上游历史记录。
