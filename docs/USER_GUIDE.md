# 教师与学生使用指南

## 第一次使用

部署者在本机交互终端执行 `npm run setup:web`，建立第一位教师／平台管理员，再运行 `npm start`。后续教师在登录页“教师注册”建立自己的教学空间；学生凭对应行政班邀请码注册。

首次进入可打开“体验入门示例”。这是本次整理新编的三个观察任务：圆形磁场、电场偏转、速度选择器；不包含私人原稿、学生信息或 API 配置。实际演示参数从界面读取。

## 教师的一次备课

1. 在“我的资源”中新建资源，或导入自己有权使用的文档。
2. 对照原文检查题干、公式、题图和候选分题；确认后添加到工作台。
3. 为一道题添加原生平面、空间或补充模型场景。需要比较时复制场景，保留原题基线。
4. 通过播放、单步、下一事件、参数和几何构造观察模型。符号关系要持续绑定，不能只在某个数值下摆出相似图形。
5. 保存个人资源，选择班级／小组发布快照，或导出资源包及离线 HTML。

参考解析、原始文档和已发布快照的范围不同；按界面的投送和导出选项确认接收者实际能看到什么。

## 班级、小组与任务

每位教师只能管理自己负责的班级和学习小组。行政班邀请码用于学生注册；学习小组由教师从自己管理的学生中组织，可以跨其所管行政班。学生保留一个行政班，可加入多个学习小组。

资源投送适合共享学习材料；学习任务适合收集学生提交、评阅和持续反馈。教师看到的是学生明确提交的作品及其版本，私人原稿的资源接口仍按所有者校验。

详细操作见 [班级与创意工坊](manuals/班级与创意工坊.md)、[作业任务与评阅](manuals/作业任务与评阅.md)。

## 学生的一次探究

1. 登录后查看所属班级／小组收到的资源和任务。
2. 打开原题场景，先提出预测，再改变一个条件观察差异。
3. 需要保留自己的修改时，保存为个人副本；不要把临时演示当作已提交任务。
4. 按任务要求提交，或把愿意公开的内容发布到工坊／讨论区。
5. 通过“账号与个性化”设置昵称、头像、背景、签名和兴趣标签。

头像与背景对已登录平台用户可见。新部署不附带任何现成师生账号或头像，需要自己创建和上传。

## 模型 API 与 AI 助手

教师在“API 连接设置”中维护默认教学连接，也可为特定班级／小组保存专属配置。学生只能选择所属范围授权的服务，或使用自己的个人连接。密钥只在服务器保存，界面不会向学生返回教师密钥。

基础沙盒和资源工作不依赖 AI。AI 请求可能向配置的服务商发送本轮题干、场景与明确选中的资料；点击发送前核对范围和服务。模型输出需按题设、公式及原生计算证据核验，候选预览不等于已经应用或保存。

自动场景生成当前仅支持原生平面模型。空间与补充模型可用于答疑和手动探究，不应被描述为已支持全部自动生成。详细说明见 [AI 学习助手与核验](manuals/AI学习助手与核验.md)。

## 工作台中的主要入口

| 想做的事 | 建议入口 |
| --- | --- |
| 回到资源库 | 工作台“资源”或“资源首页” |
| 切换题目、场景 | 题目目录、场景选择器 |
| 对照题干与原图 | “原题”面板 |
| 画几何、约束和场域 | 沙盒分类工具窗 |
| 查看时刻、阶段与临界事件 | 时间轴、下一事件、运动曲线 |
| 保存新变式 | 复制场景后保存个人资源 |
| 修改布局 | 个人工作区和面板设置 |
| 了解新版变化 | 首页侧栏底部或手机“更多”中的更新记录 |

更细的界面说明保留在 [工作台操作指南](manuals/工作台操作指南.md)、[动态几何构造](manuals/动态几何构造.md)、[图形公式与手写识别](manuals/图形公式与手写识别.md)。这些手册中早期的验收叙述是历史上下文，当前部署步骤以公开版文档为准。

## 桌面与离线使用

网页运行包需要 Node 服务；导出的单个离线 HTML 可以在兼容浏览器中独立查看和操作所导出的内容。离线文件不提供网页账号、服务器保存或在线模型连接。

Electron 开发启动方法见 [开发指南](DEVELOPMENT.md)。历史安培力、洛伦兹力单文件构建能力和已授权教学素材仍在源码中；可选专题 DOCX 加工流程见 [teaching/README.md](../teaching/README.md)。

## 微信与平台管理

微信绑定入口默认显示待开通。需要维护者完成官方应用、域名、凭据配置与真实联调，才可开启；参见 [微信登录接入说明](manuals/微信登录接入说明.md)。

平台管理员可管理教师账号，但不通过界面读取其他教师的 API 密钥。升级或恢复账号时，注意新版与旧单教师版本的权限模型不同，不能直接把旧程序覆盖到含新教师账号的数据目录。
